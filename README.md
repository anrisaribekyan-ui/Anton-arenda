# Читалка на слух

Android-приложение: читает книги нейроголосом Silero, ускоряет с шагом 0,1 (до х8 без «мультяшного» голоса) и каждые N минут задаёт вопросы по прослушанному через DeepSeek.

```
телефон ──текст фрагмента──▶ твой VPS (Silero) ──ogg──▶ телефон (ExoPlayer, скорость)
телефон ──прослушанный текст──▶ DeepSeek ──вопросы──▶ телефон
```

## 1. Сервер озвучки на VPS

Нужны Docker и ~2 ГБ свободной памяти. Первый запуск скачает модель Silero (~100 МБ).

```bash
git clone <этот репозиторий> chitalka && cd chitalka/server
echo "TTS_TOKEN=$(openssl rand -hex 24)" > .env
cat .env                      # этот токен вставишь в приложение
docker compose up -d --build
curl http://localhost:8010/health
```

Проверка озвучки:

```bash
curl -X POST http://localhost:8010/tts \
  -H "Authorization: Bearer $(grep TTS_TOKEN .env | cut -d= -f2)" \
  -H "Content-Type: application/json" \
  -d '{"text":"Привет, это проверка голоса.","speaker":"xenia"}' -o test.ogg
```

Адрес для приложения: `http://IP_СЕРВЕРА:8010`. Открой порт 8010 в фаерволе.

**Лучше через HTTPS.** Если на сервере есть nginx и поддомен, в `docker-compose.yml` замени порт на `127.0.0.1:8010:8000` и добавь:

```nginx
server {
    server_name tts.example.ru;
    location / {
        proxy_pass http://127.0.0.1:8010;
        proxy_read_timeout 180s;
    }
    # listen 443 ssl; сертификаты — через certbot --nginx
}
```

Настройки в `docker-compose.yml`:
- `TORCH_THREADS` — сколько ядер отдавать озвучке;
- `CACHE_DAYS` — сколько дней хранить готовое аудио на сервере.

## 2. Приложение

APK собирает GitHub Actions при каждом пуше в `main`. Готовый файл лежит в разделе **Releases** репозитория — открой его с телефона и установи (разреши установку из браузера).

В приложении: **Настройки** → адрес сервера, токен, голос, ключ DeepSeek, интервал опросов → **Сохранить**. Потом **Добавить книгу**.

## Как это работает

- Книга режется на фрагменты ~700 знаков по границам предложений.
- Приложение заранее озвучивает 4 следующих фрагмента и удаляет прослушанные старше 10 фрагментов назад, чтобы не забивать память.
- Скорость меняет плеер, а не синтез: голос остаётся чистым и тон не меняется.
- Опрос срабатывает на границе фрагмента после N минут реального прослушивания. Вопросы строятся только по тексту, прослушанному с прошлого опроса.
- В настройках видно, какой процент верных ответов на каждой скорости, — это твой реальный потолок.
- Ключ DeepSeek хранится только на телефоне.
